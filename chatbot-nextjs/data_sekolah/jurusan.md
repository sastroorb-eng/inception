# Program Keahlian (Jurusan)

SMK Telekomunikasi Tunas Harapan menyediakan 4 Konsentrasi Keahlian utama yang diselaraskan dengan kebutuhan industri masa depan:

1. **Pengembangan Perangkat Lunak dan Gim (PPLG) / Rekayasa Perangkat Lunak (RPL)**
   Fokus pada pemrograman web, software, dan game developer.
2. **Teknik Jaringan Komputer dan Telekomunikasi (TJKT) / TKJ**
   Fokus pada infrastruktur jaringan, hardware, dan administrasi server. TKJ di sini bekerja sama dengan LSP Teknologi Digital untuk memberikan sertifikasi profesi Network Administrator Muda kepada siswa lulusannya.
3. **Desain Komunikasi Visual (DKV)**
   Fokus pada desain grafis, multimedia, dan kreativitas visual.
4. **Teknik Kendaraan Ringan (TKR) / Otomotif**
   Fokus pada perawatan, perbaikan, dan teknologi mesin kendaraan otomotif.
